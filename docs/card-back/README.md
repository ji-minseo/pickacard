# Pick a Card card back

Three vector prototypes compared in browser at 50×75 and 90×135, repeated ten times: ivory diamond/light, burgundy two paths/light, ivory paired moons. Chosen: 02 two paths. Ivory option was less distinct from fronts; moons carried more familiar tarot symbolism. Two paths is a restrained custom emblem for choosing and intuition, with a muted gold central light.

Final public/artwork/card-back.svg: burgundy field, ivory/rose engraving lines, small ochre light, thin double print border, four restrained corner marks and symmetric low-opacity paper flecks. No lettering, pseudo-text, scene, noise animation, gradients or external references. Every asymmetric path and grain element has an identical 180° counterpart. Rectangles and the center light are individually rotationally symmetric. No card identity or orientation changes the back.

CSS serves one shared small SVG for all facedown cards, with subtle pointer-only hover lift/shadow, press feedback and selected outline. Existing draw and flip logic preserved. Reduced motion respected. Prototype resources live only in docs, outside deployed assets.
